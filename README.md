# EP Daily View launcher

Static home-screen launcher for the Economos Properties Daily View web app.

Open this page in Safari, then Share → Add to Home Screen (Open as Web App on).
The home-screen icon is the official Economos Properties monogram. Opening the
icon loads the Apps Script app:
